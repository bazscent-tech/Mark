# 🏪 سوق الجمله اليمني | Yemeni Wholesale Market

أكبر منصة تجارية بالجملة في اليمن — آلاف المنتجات بأسعار الجملة مع ضمان الجودة وتوصيل سريع.

## ✨ المميزات

### 🛍️ واجهة المتجر
- الصفحة الرئيسية مع بنرات وعروض فلاش
- تصنيفات رئيسية وفرعية
- عرض المنتجات بالشبكة مع فلترة وفرز
- صفحة تفاصيل المنتج مع معرض صور
- نظام تقييمات ومراجعات
- بحث ذكي

### 🛒 نظام المشتري
- سلة مشتريات كاملة
- إتمام الطلب مع معلومات الشحن
- طرق دفع متعددة (عند الاستلام، محفظة إلكترونية، تحويل بنكي)
- تتبع الطلبات
- تسجيل دخول وإنشاء حساب

### 🏪 لوحة التاجر
- لوحة تحكم بالإحصائيات
- إدارة المنتجات (إضافة، تعديل، حذف)
- إدارة الطلبات (قبول، شحن، توصيل)
- تقارير المبيعات
- إعدادات المتجر

### 🎨 التصميم
- تصميم عصري واحترافي
- دعم كامل للغة العربية (RTL)
- متجاوب مع جميع الشاشات
- نظام ألوان متناسق
- أيقونات Emoji بدون مكتبات خارجية

## 🚀 التقنيات

- **HTML5** - هيكل الصفحة
- **CSS3** - التصميم والتنسيق
- **Vanilla JavaScript** - المنطق والتفاعل
- **SPA** - تطبيق صفحة واحدة مع نظام توجيه
